# Mock2Master Documentation

## Vision

Mock2Master is an AI-powered test analysis platform built for JEE aspirants.

Instead of showing only marks, Mock2Master helps students understand:

- Why they lost marks
- Which topics are weak
- Which mistakes repeat frequently
- How to improve efficiently

---

## Mission

Transform every mock test into a personalized improvement roadmap.
